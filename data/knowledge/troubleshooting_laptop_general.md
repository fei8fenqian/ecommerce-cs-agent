# 笔记本故障排查 — 通用流程

最后更新：2026 年 7 月

品牌无关的通用排查树，适用于所有品牌笔记本（Apple / 华为 / 联想 / 华硕 / 惠普 / 戴尔等）。

---

## 第零步：判断在保状态（Agent 必须先做这一步）

Agent 在开始故障排查之前，**必须先用 track_order 查订单**，根据签收日期判断保修状态，走不同分支：

```
用户反馈故障
  │
  ├── 0. track_order(order_id) → 查签收日期 + 订单状态
  │     │
  │     ├── 签收 ≤ 15 天 → 硬件故障免费换新
  │     │     └── 引导用户走换货流程（after_sales.md）
  │     │
  │     ├── 签收 ≤ 1 年（整机保修期）→ 官方免费保修
  │     │     └── 建议去品牌官方售后（省时省力）
  │     │
  │     ├── 签收 ≤ 2 年（主要部件保修期，主板/CPU/屏幕等）
  │     │     └── 判断是否可能是主要部件故障？
  │     │         ├── 可能 → 引导官方售后（还能免费修）
  │     │         └── 不太可能是主要部件 → 进入 DIY 排查
  │     │
  │     └── 已过保 / 状态异常（已取消/已退款）→ 直接 DIY 排查
  │
  └── 在保 → 优先官方售后，同时提供排查参考
       过保 → 完整 DIY 排查 + 付费维修建议
```

**保修期限速查**（详见 after_sales.md）：

| 品类 | 整机 | 主要部件 |
|------|:---:|:---:|
| 笔记本 | 1 年 | 主板/CPU/内存/显卡/屏幕 2 年 |
| 台式机 | 1 年 | 主板/CPU/显卡/电源 3 年 |
| 手机/平板 | 1 年 | 主板/屏幕/摄像头 2 年 |
| 显示器 | 1 年 | 面板 3 年 |

**不保修的情况**：进水（防水标变红）、碎屏/摔伤、私自拆机/私修、越狱/Root。

## 排查决策树（过保后或用户坚持自己排查时使用）

```
用户反馈"笔记本开不了机"
  │
  ├── 1. 电源检查
  │     ├── 适配器指示灯不亮 → 换适配器/插座测试
  │     ├── 电池可拆卸 → 取下电池，仅用适配器开机
  │     └── 电池不可拆卸 → 充电 30 分钟后再试
  │
  ├── 2. 强制重启（放电）
  │     └── 长按电源键 10-15 秒 → 松开等 30 秒 → 正常按开机
  │
  ├── 3. 拔掉所有外设
  │     └── 拔掉 USB 设备/外接显示器/SD 卡 → 只留适配器 → 开机
  │
  ├── 4. 释放静电
  │     ├── 可拆卸电池：取出电池 → 长按电源键 3-5 次 → 等 30 秒
  │     └── 不可拆卸：长按电源键 15 秒以上 → 等 30 秒
  │
  └── 5. 观察开机现象 → 进入对应排查路径（见下方）
```

## 按现象分类排查

### 现象 A：按下电源键完全无反应（无灯、无风扇、无声音）

**可能原因（按概率排序）**：电源适配器损坏 > 电池过放保护 > 主板电源电路故障

排查步骤：
1. 换一个兼容的电源适配器测试
2. 充电 30 分钟以上后再试（电池过放保护恢复需要时间）
3. 以上都无效 → 主板硬件故障，送修

### 现象 B：指示灯亮、风扇转，但屏幕全黑

**可能原因**：内存接触不良 > 显示屏故障 > 显卡故障 > 系统引导文件损坏

排查步骤：
1. 外接显示器（HDMI/Type-C）→ 外接正常？→ 笔记本屏幕故障
2. 外接也黑 → 重新插拔内存条（如有动手能力）：取下 → 橡皮擦清洁金手指 → 插紧
3. 尝试进入 BIOS（开机时按 F2 / F1 / Delete）
   - 能进 BIOS → 系统/SSD 问题，查下一步
   - 不能进 BIOS → 主板/CPU 硬件故障，送修

### 现象 C：开机卡在品牌 Logo 界面

**可能原因**：USB 设备不兼容 > 系统文件损坏 > SSD 故障 > BIOS 异常

排查步骤：
1. 拔掉所有 USB 设备，强制重启
2. 进入安全模式（Windows: 开机反复按 F8）
3. 进入 BIOS → 加载默认设置 → 保存退出
4. 以上无效 → 可能是 SSD 故障，送修

### 现象 D：蓝屏（Windows）

**可能原因**：驱动冲突 > 内存故障 > 系统文件损坏 > SSD 故障

排查步骤：
1. 记录蓝屏错误代码（如 0x0000007B = SATA 模式错误）
2. 重启进入安全模式 → 卸载最近安装的软件/驱动
3. 安全模式下运行 `sfc /scannow` 修复系统文件
4. 如果安全模式也蓝屏 → 内存或 SSD 硬件故障，送修

### 现象 E：开机后桌面只有鼠标光标（黑屏但有光标）

**可能原因**：explorer.exe 未启动 > 第三方软件冲突

排查步骤：
1. Ctrl+Shift+Esc 打开任务管理器 → 运行新任务 → `explorer.exe` → 确定
2. 无效 → 运行 `msconfig` → 诊断启动 → 重启

### 现象 F：反复重启 / 自动关机

**可能原因**：过热保护 > 电源适配器供电不足 > 主板故障

排查步骤：
1. 检查通风口是否堵塞 → 冷却 30 分钟
2. 听风扇是否运转正常
3. 进 BIOS 查看 CPU 温度（如支持）
4. 仅在运行大型程序时重启 → 散热硅脂干了，清灰换硅脂
5. 待机也重启 → 主板供电故障，送修

## 软件 vs 硬件故障速查

| 判断标准 | 倾向软件 | 倾向硬件 |
|----------|:---:|:---:|
| 能进 BIOS 但进不了系统 | ✅ | — |
| 安全模式正常，普通模式异常 | ✅ | — |
| 外接设备拔掉后恢复正常 | ✅ | — |
| 重装系统后问题消失 | ✅ | — |
| 开机有蜂鸣声/报错码 | — | ✅ |
| 在 BIOS 里也死机/花屏 | — | ✅ |
| 多个操作系统都异常 | — | ✅ |

## 保修判断

根据 after_sales.md：
- 签收 **15 天内**硬件故障（非人为）→ 免费换新
- 整机 **1 年**保修，主要部件（主板/CPU/屏幕）**2-3 年**
- 人为损坏（进水/碎屏/摔伤/私拆）→ 不保修

Agent 排查故障时：
1. 先用 `track_order` 查签收日期，判断在保/过保
2. 在保 → 优先引导官方售后
3. 过保 → 提供 DIY 排查建议 + 付费维修选项
