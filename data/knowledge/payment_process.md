# 支付流程

## 当前支付能力范围

当前商城 checkout 只接入支付宝沙箱。客户创建订单、继续付款和取消待支付订单均由受控 API 与确定性服务处理；Agent 不能用聊天文本创建支付订单或支付交易。

## 创建付款订单时的服务端核验

创建 checkout 前，服务端核验商品存在、库存满足数量、金额为正且购买数量在允许范围内。通过核验后订单仍是待支付状态；生成收银台表单或二维码不等于付款成功。

## 继续支付已有订单

只有当前客户本人仍处于待支付状态的商城订单可以重新打开支付宝付款入口。继续支付会复用该待支付订单，不应由 Agent 建议重复创建新的订单。

## 取消待支付订单

客户取消待支付订单时，服务端会先收敛支付宝交易事实，再关闭待支付交易并更新本地订单。已经支付、状态已变化或无法确认支付渠道状态时，系统不会把订单当作可安全取消。
