# 安卓手机故障排查 — 通用流程

最后更新：2026 年 7 月

适用品牌：华为、小米/Redmi、OPPO、vivo/iQOO、荣耀、三星等所有安卓手机。

---

## 各品牌进入 Recovery 模式按键

| 品牌 | 按键组合 |
|------|----------|
| 华为 / 荣耀 | 关机后同时按住 **电源键 + 音量上键** 约 10-15 秒 |
| 小米 / Redmi | 关机后同时按住 **电源键 + 音量上键** 约 8 秒，出现 Mi Logo 松开 |
| OPPO | 关机后同时按住 **电源键 + 音量上键**（部分机型音量下键） |
| vivo / iQOO | 关机后同时按住 **电源键 + 音量上键** |
| 三星 | 关机后同时按住 **电源键 + 音量上键** 约 10 秒 |

各品牌进入 Fastboot 模式：关机后按住 **电源键 + 音量下键**。

---

## 排查决策树

```
手机卡 Logo / 无限重启 / 无法开机
  │
  ├── 1. 强制重启（不丢数据）
  │     └── 同时长按 电源键 + 音量下键 10-15 秒
  │
  ├── 2. 充 电 30 分钟
  │     └── 换原装充电器 + 数据线
  │
  ├── 3. 能进 Recovery？
  │     ├── 是 → 清除缓存分区（Wipe Cache，不丢数据）
  │     │      → 无效 → 恢复出厂设置（⚠️ 清除用户数据）
  │     └── 否 → 进入第 4 步
  │
  ├── 4. 能进 Fastboot？
  │     ├── 是 → 使用官方工具线刷固件
  │     └── 否 → 送修（硬件故障）
  │
  └── 5. 所有软件修复无效 → 送修
```

---

## 修复操作详解

### 1. 清除缓存分区（Wipe Cache Partition）⭐ 首选

- **不删除个人数据**（照片、微信聊天记录等），只清除系统临时缓存
- 进入 Recovery → 音量键选择 "Wipe Cache Partition" → 电源键确认 → 重启
- 适合：OTA 升级后卡顿、偶尔重启、卡在 Logo

### 2. 恢复出厂设置（Wipe Data/Factory Reset）

- ⚠️ **清除所有应用、账户、设置**，但内部存储文件（照片/视频/文档）通常不删
- Recovery → Wipe Data/Factory Reset → 确认 → 重启
- 首次开机可能需要 2-5 分钟

### 3. 线刷官方固件（高级操作）

- 适合：Recovery 损坏、双清无效、无法进入系统
- 需要：电脑 + USB 数据线 + 官方固件包 + 品牌刷机工具

| 品牌 | 工具 | 刷机模式 |
|------|------|----------|
| 华为/荣耀 | HiSuite（华为手机助手） | eRecovery 或 Fastboot |
| 小米/Redmi | MiFlash | Fastboot（电源+音量下） |
| OPPO | ColorOS Recovery Tool | Fastboot |
| vivo | vivo Flash Tool | Fastboot |

### 4. 华为 eRecovery（华为专属，推荐）

无需手动下载固件：
1. 关机后同时长按 电源键 + 音量上键 约 15 秒
2. 看到 eRecovery 界面松手
3. 连接 Wi-Fi → "下载最新版本并恢复"
4. 自动下载并安装官方固件

## 常见现象判断

| 现象 | 大概率原因 | 优先级处理 |
|------|-----------|----------|
| 能进 Recovery | 系统软件问题 | 清除缓存 → 双清 |
| 能进 Fastboot 但进不了 Recovery | Recovery 分区损坏 | 线刷官方固件 |
| 充电有反应但不开机 | 电池老化（>2 年） | 换电池测试 |
| 完全无反应（无振动、无充电指示） | 主板/电源 IC 硬件故障 | 送修 |
| 摔落后出现故障 | 芯片虚焊/排线松动 | 送修 |
| 进水后故障 | 主板腐蚀/短路 | 立即关机送修 |

---

## 操作注意

- ✅ 操作前确保电量 50% 以上
- ✅ 使用官方固件，不刷第三方 ROM
- ⚠️ 刷机中途**严禁断开数据线或关机**
- ⚠️ 首次开机可能较慢（2-5 分钟），正常现象
