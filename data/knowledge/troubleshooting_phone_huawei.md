# 华为手机故障排查 — EMUI / HarmonyOS 特有

最后更新：2026 年 7 月

适用机型：华为 Mate 系列、P 系列、nova 系列（EMUI 12+ / HarmonyOS 2+）。

---

## 华为特有功能

| 功能 | 操作 |
|------|------|
| 进入 Recovery | 关机后同时按住 电源键 + 音量上键 10-15 秒 |
| eRecovery（在线修复） | 关机后同时按住 电源键 + 音量上键 15 秒以上（比 Recovery 多按一会） |
| 进入 Fastboot | 关机后按住 电源键 + 音量下键 |
| 强制重启 | 长按电源键 10 秒以上 |

## 故障分支

### 1. 华为手机无限重启（持续重启 3-5 分钟一次）

这是华为的系统保护机制——检测到严重错误后自动重启收集日志，常见原因：
- 存储空间满 → 清理存储后正常
- 第三方应用崩溃（尤其是输入法/桌面启动器）→ 安全模式卸载
- 系统 OTA 升级中断 → eRecovery 修复

### 2. 进入安全模式

如果怀疑是第三方 App 导致的问题：
1. 关机
2. 开机直到看到 HUAWEI Logo
3. 马上按住音量下键直到进入系统
4. 屏幕左下角显示"安全模式" → 卸载最近安装的可疑 App → 重启

### 3. eRecovery 在线修复

华为最实用的功能——不需要电脑，不需要下载固件包：
1. 关机
2. 同时长按电源键 + 音量上键 约 15 秒
3. 看到 eRecovery 界面松手
4. 连接可用的 Wi-Fi
5. 选择"下载最新版本并恢复"
6. 系统自动从华为服务器下载匹配的固件并安装
7. 数据会被清除

### 4. 华为手机提示"系统文件损坏"

1. 尝试 eRecovery 在线修复
2. 如果 eRecovery 失败 → 用 HiSuite（华为手机助手，电脑端）连接 → 系统修复
3. 如果 HiSuite 也修复不了 → 送华为服务中心

### 5. 升级 HarmonyOS 后卡顿/重启

1. 先等 1-2 天——系统升级后后台在做索引和优化，正常的
2. 如果持续 3 天以上 → 清除缓存分区（Recovery → Wipe Cache）
3. 仍然异常 → eRecovery 恢复
