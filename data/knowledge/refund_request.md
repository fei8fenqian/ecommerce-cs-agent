# 退款申请

## 当前支持范围

当前商城只对**当前登录客户本人**的应用自有 checkout 订单提供全额退款自助流程。历史 legacy
订单、其他客户订单和无法核验的订单不进入此流程。

退款资格由服务端核验；只有订单已支付、支付交易已成功且币种为 CNY、订单仍处于待履约状态、支付成功
未超过 7 天，并且已核验支付金额为正且与订单金额一致时，首版流程才可能允许申请。

## 用户说“我要退款”时

Agent 必须先识别具体订单。存在多笔候选订单时，先让客户选择，不能默认把“最近一单”当作退款对象。

随后按当前登录身份读取两项动态事实：该订单是否已有退款记录，以及是否满足首版退款资格。它们必须来自
订单/退款工具和服务端，不从聊天内容或本篇文档推断。

## 可以交付自助入口时

仅当系统已确认“没有已有退款记录”且“资格通过”时，服务端才会生成可信的订单页入口。Agent 的完成动作
是交付该入口，并说明客户需要在订单页填写原因和确认提交。

Agent 不创建退款、不确认退款、不调用支付渠道，也不自行拼接退款链接。

## 已有退款或不符合资格时

已有退款记录时，转为查询和说明该记录的当前状态，不能重复申请。

资格结果当前只有“通过/不通过”这一结论。若没有其他已核验事实，Agent 不得猜测不通过的具体原因，也
不得承诺可以人工绕过规则。

## 金额与确认边界

退款金额由服务端从已核验支付交易读取，客户和 Agent 都不能填写或修改金额。客户在订单页明确确认后，
确定性退款服务才会提交一次支付宝沙箱退款；这不等于 Agent 自动退款。
