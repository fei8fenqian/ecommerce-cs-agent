# 小米/Redmi 手机故障排查 — MIUI / HyperOS 特有

最后更新：2026 年 7 月

适用机型：小米数字系列、Redmi 系列（MIUI 13+ / HyperOS）。

---

## 小米特有功能

| 功能 | 操作 |
|------|------|
| 进入 Recovery | 关机后同时按住 电源键 + 音量上键 约 8 秒 |
| 进入 Fastboot | 关机后按住 电源键 + 音量下键 |
| 强制重启 | 长按电源键 10 秒以上 |
| 官方刷机工具 | PC 端 MiFlash（线刷）/ 手机端系统更新（卡刷） |

## 故障分支

### 1. 小米手机卡在 MIUI/HyperOS Logo 长时间不动

这是最常被反馈的问题，通常不是硬件故障：
1. 关机 → 重启 → 多等 5 分钟（首次开机/升级后首次开机可能很慢）
2. 如果超过 10 分钟 → 强制重启再试一次
3. 仍然卡住 → Recovery → Wipe Cache → 重启

### 2. 小米手机无限重启（MIUI 经典问题）

常见原因（按概率）：
- 系统升级包下载损坏 → Recovery → Wipe Cache → 重启
- 桌面启动器（System Launcher）崩溃 → Recovery → 双清
- 第三方主题/字体不兼容 → 安全模式 → 恢复默认主题
- 电池排线接触不良（尤其 Redmi 机型）→ 送修

### 3. 进入安全模式

1. 关机
2. 开机直到看到 Mi Logo
3. 马上按住音量下键直到进入系统
4. 屏幕左下角显示"安全模式"
5. 设置 → 应用 → 卸载最近安装的可疑 App → 重启

### 4. Recovery 模式详解

小米的 Recovery 界面（MIUI Recovery 5.0）选项：

| 选项 | 作用 | 影响数据 |
|------|------|:---:|
| 重启手机 | 正常重启 | 不影响 |
| 清除数据 | Wipe Data（双清） | ⚠️ 清除所有用户数据 |
| 连接小米助手 | PC 端操作 | 按操作而定 |
| 安全模式 | 仅加载系统核心 | 不影响 |

### 5. 线刷（Fastboot + MiFlash）

适合 Recovery 进不去、系统严重损坏的情况：
1. PC 安装 MiFlash 工具 + 小米 USB 驱动
2. 从 miui.com 下载与**机型/版本完全匹配**的 Fastboot 线刷包
3. 手机关机 → 按住音量下 + 电源 → 进入 Fastboot → 连接电脑
4. MiFlash 加载刷机包 → 全部删除 → 刷机
5. ⚠️ 刷机期间**绝对不能断开 USB 线**

> 注意：小米官方线刷包的下载页面在 miui.com，需要登录小米账号。线刷包分为**卡刷包（Recovery ROM）**和**线刷包（Fastboot ROM）**，Recovery 修复用卡刷包，Fastboot 修复用线刷包。

### 6. 电池老化判断

小米手机电池老化会直接导致 CPU 降频，表现为突然卡顿、自动关机（特别是冬天低温时）。如果手机使用超过 2 年，电池很可能是罪魁祸首。更换电池费用约 ¥100-200。
