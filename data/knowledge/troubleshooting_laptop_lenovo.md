# 联想笔记本故障排查 — ThinkPad / Lenovo 特有

最后更新：2026 年 7 月
数据来源：联想知识库 (iknow.lenovo.com.cn)

适用机型：ThinkPad 系列、Lenovo 消费系列（小新/YOGA/拯救者等）。

---

## 联想特有功能键

| 功能 | 操作 |
|------|------|
| 进入 BIOS | 开机时不停按 **F2**（部分 ThinkPad 为 **F1**） |
| 加载 BIOS 默认值 | BIOS 中按 **F9** → Yes → Enter |
| 保存并退出 BIOS | BIOS 中按 **F10** → Yes → Enter |
| 启动菜单 | 开机时按 **F12** |
| 系统恢复 | 开机时按 **F11**（部分机型） |
| PC Doctor 硬件诊断 | 开机自检时按 **F11** 或 **Access IBM 按钮** |

## ThinkPad 开机自检（POST）错误码速查

### 主板/EEPROM 类

| 错误码 | 含义 | 处理 |
|--------|------|------|
| 0175 | EEPROM 校验错误 | 更换主板 |
| 0176 | 系统安全相关 | BIOS → F10 保存，无效则换主板 |
| 0190 | 电池电量极低 | 连接电源适配器充电 |
| 0251 | CMOS 校验和错误 | 更换主板纽扣电池 |

### 硬盘/存储类

| 错误码 | 含义 | 处理 |
|--------|------|------|
| 0200 | 硬盘错误 | 重新插拔硬盘，F9 恢复 BIOS |
| 2100/2101/2102 | 硬盘检测错误 | 重新插拔或送修 |
| 2010 | 使用了非原厂/不兼容硬盘 | 按 ESC 可继续但存在风险 |

### 其他报错

| 错误码/提示 | 含义 | 处理 |
|------------|------|------|
| Fan Error | 风扇故障 | 立即关机送修 |
| Error 1962 | 引导异常或硬盘故障 | 检查 BIOS 硬盘识别 |
| Error 0135 | CPU 风扇报错 | 清洁风扇或更换 |
| Thermal sensing error | 热传感器故障 | 更换主板 |

## 故障分支

### 1. 完全无反应

除了通用排查外，联想特别注意：
1. 拔掉电源 → 取出电池（可拆卸机型）→ 长按电源键 3-5 次释放静电 → 等 30 秒
2. 仅用适配器（不装电池）开机测试

### 2. 开机黑屏但风扇转

1. 外接显示器测试
2. 重新插拔内存条
3. F2 进 BIOS → F9 加载默认值 → F10 保存

### 3. 开机卡在 Lenovo Logo

1. 拔掉所有 USB 设备
2. F2 进 BIOS → F9 加载默认值 → 确认硬盘是否被识别
   - 硬盘未被识别 → 硬盘/连接线/主板故障，送修
   - 硬盘被识别 → F10 保存退出 → 重新开机

### 4. 蓝屏 0x0000007B

这是 SATA 模式错误：
1. F2 进 BIOS → Configuration → SATA Controller Mode
2. 当前是 AHCI → 改为 Compatible（反之亦然）
3. F10 保存退出
4. 如果仍蓝屏 → F8 安全模式 → 卸载最近安装的驱动

### 5. S.M.A.R.T. 硬盘预警

报错信息：`S.M.A.R.T. Status BAD` 或 `SMART Failure Predicted`
- **立即备份所有重要数据！**
- 这是硬盘自我监测报告"硬盘即将损坏"，不是误报
- 备份后 → 送联想服务网点更换硬盘

### 6. 待机/休眠唤醒后黑屏

1. 移除非标配的内存和外接设备
2. 升级显卡驱动 + BIOS 到最新版
3. 禁用第三方安全软件后测试
4. 以上无效 → 恢复出厂设置

## 联想官方硬件诊断方法

### PC Doctor（硬件检测）
- 开机按 F11 → 进入 PC Doctor 诊断
- 可检测：CPU、内存、硬盘、主板传感器
- DOS 环境下运行，不需要进系统

### HD Tune（硬盘坏道扫描）
- 免费工具 → Error Scan 选项卡 → Start
- 绿色块 = 正常，红色块 = 物理坏道（需更换硬盘）
