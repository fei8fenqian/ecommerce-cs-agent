# 以旧换新政策

最后更新：2026 年 7 月

---

## 一、支持品类

以下品类支持以旧换新：

| 品类 | 说明 |
|------|------|
| 手机 | 不限品牌，不限新旧程度 |
| 平板 | iPad 和安卓平板均支持 |
| 笔记本 | 不限品牌，含 MacBook 和 Windows 本 |
| 智能手表 | Apple Watch、华为 Watch 等主流品牌 |
| 游戏主机 | PS5、Xbox Series、Switch 系列 |
| 耳机/音箱 | 仅限品牌蓝牙耳机和智能音箱 |

## 二、估价等级

根据成色、功能、配件齐全度分为三个等级：

### A 级（优质）

- 屏幕无划痕或仅细微使用痕迹
- 机身无明显磕碰
- 所有功能正常（摄像头、按键、指纹/面容、充电口）
- 无拆修记录
- 配件齐全（充电器、数据线、包装盒）
- 电池健康度 > 80%（手机/平板）
- **估价：同类二手市场价的上限**

### B 级（良好）

- 屏幕有可见划痕（亮屏后不影响使用）
- 机身有轻微磕碰或掉漆
- 所有功能正常
- 允许官方售后有过维修记录（需提供记录）
- 配件可接受缺失数据线或包装盒
- **估价：同类二手市场价的中位数**

### C 级（一般）

- 屏幕有深划痕或碎裂（触控仍正常）
- 机身有明显磕碰或变形
- 部分功能异常（详见下方"不收的情况"）
- 有过第三方维修
- 配件不全
- 电池健康度 < 80%
- **估价：同类二手市场价的底线，或直接不收**

### 不收的情况

- 屏幕完全碎裂、触控失效
- 进水且功能异常（防水标变红 + 无法开机/摄像头起雾）
- 无法正常开机
- 账号未退出（iPhone 的 iCloud 锁、华为的华为账号锁）
- 主板维修过
- 山寨/高仿机
- IMEI/序列号与机身不符（组装机/换壳机）

## 三、平台补贴

旧机抵扣金额的基础上，平台额外给予补贴：

| 新机价位 | 手机以旧换新补贴 | 笔记本以旧换新补贴 |
|---------|:---:|:---:|
| 3000 元以下 | +100 元 | — |
| 3000-6000 元 | +200 元 | +200 元 |
| 6000-10000 元 | +350 元 | +500 元 |
| 10000 元以上 | +500 元 | +1000 元 |

补贴发放到"极客数码"账户余额，可用于本次或下次购物。

平台补贴可以叠加品牌以旧换新补贴：
- Apple Trade In：额外折抵（Apple 官网自行估价，与平台补贴可叠加）
- 华为以旧换新：额外 ¥100-300（限华为品牌新机）
- 小米以旧换新：额外 ¥50-200 + 赠品（限小米品牌新机）

## 四、以旧换新流程

### 线上下单

1. 选购新机 → 加入购物车 → 选择"以旧换新"
2. 填写旧机信息：品牌、型号、存储容量、成色自评、是否维修过
3. 系统预估回收价（仅为预估价，最终价以验机为准）
4. 提交订单 → 支付时只付差价（新机价格 - 预估回收价 - 平台补贴）
5. 快递送货上门 + 当场回收旧机（快递员初步检查）
6. 旧机送回仓库 → 专业验机（1-3 个工作日）
7. 最终报价：价格有变动会短信/电话通知确认
   - 接受 → 差额多退少补
   - 不接受 → 旧机退回，新机按原价支付（补贴取消）

## 五、常见问题

### 旧机数据怎么处理？

收旧机后我们会恢复出厂设置并做数据擦除。但为了您的隐私安全，**寄出前请自行备份并退出所有账号**（Apple ID / 华为账号 / 三星账户 / 小米账户），关闭"查找我的设备"。如果寄出时账号未退出，可能视为 C 级或拒收。

### 旧机估价和新机优惠能分开用吗？

不能。以旧换新必须在购买新机时同时使用。旧机不能单独回收。

### 多台旧机能换一台新机吗？

不能。一台旧机换一台新机。

### 以旧换新的旧机还能退货吗？

旧机已寄出并完成验机的，旧机不退回。新机仍需按正常流程退换（参照售后政策）。
