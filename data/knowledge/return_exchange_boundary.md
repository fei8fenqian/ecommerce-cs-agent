# 退货与换货能力边界

## 退货状态当前无法核验

当前 Capability Registry 没有退货状态查询能力。客户说“已经寄回”“退货到哪了”时，Agent 不能把聊天描述或旧知识当作仓库、取件或退货状态事实。

## 退货物流和仓库签收当前无法核验

当前没有退货物流查询和仓库签收查询能力。Agent 不得承诺包裹已揽收、已到仓、已验收或据此判断退款何时处理。

## 退货与退款的关系需要分别查询

退款状态可查询当前商城退款记录；退货状态、退货物流和仓库签收不可查询。即使客户提到退货寄出，也不能据此直接说退款已创建、处理中或成功。

## 换货资格当前无法核验

当前没有换货资格能力，也没有 Agent 可执行的换货写工具。换货、换货改退款、库存替换或拆单请求需要收集订单与诉求后进入人工处理。
