# 本人订单查询

## 订单信息属于动态事实

订单状态、商品、金额、物流单号和支付状态必须从订单工具或本人订单 API 查询。知识库不得保存或复述某个客户的订单事实。

## 查询范围只限当前登录客户

“我的订单”“帮我查订单”只会读取当前登录客户已归属的订单。订单不存在和无权读取统一不暴露为他人订单信息；历史未归属订单不会通过客户订单接口返回。

## 没有订单号时的处理

没有订单号时，工具可返回当前客户最近的多笔订单。若有多个候选，Agent 应展示可见的商品、订单号和履约阶段，让客户选择，不能自行猜测“最近买的那台”。

## 订单号与手机号的边界

SO 开头订单号用于精确查询当前商城 checkout 订单。手机号只用于兼容已确认归属的历史订单查询条件，客户身份而不是手机号决定资源范围。
